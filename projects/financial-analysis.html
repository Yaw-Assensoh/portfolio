How did tech stocks perform against the broader market?

Tech stocks are widely known for growth. But quantifying that growth against a benchmark — and understanding the volatility behind it — is what separates a claim from a data-driven insight.

Tech stocks delivered 243% average returns vs 100% SPY — but TSLA's 343.9% came with 52.3% volatility

Over the 5-year analysis window, every tech stock in the group outperformed the SPY benchmark significantly. The average return across all tech stocks was 243% — more than double the market benchmark. TSLA led at 343.9%, followed by GOOGL at 251.0% and AMZN at 210.4%.

However, return without risk context is incomplete information. TSLA's 52.3% annualised volatility means its price swings are more than double that of MSFT (24.5%). An investor who only looked at returns would miss the full picture. The risk-return framework reveals that MSFT offers the optimal balance: 158% returns with market-like volatility.

For context: a stock with 52% volatility can swing ±52% in a single year. That is not a core holding for most portfolios — it is a tactical position.

So what?For portfolio construction, MSFT should be the core holding, TSFL a satellite position limited to 5-10% of the portfolio. The risk-return scatter plot identifies exactly where each stock sits on the efficient frontier — enabling evidence-based position sizing rather than instinct-based allocation.

What do momentum signals tell us about tactical allocation?

If returns show what happened, momentum signals suggest what might happen next. Divergent RSI readings across tech stocks create tactical opportunities — but only if you have a framework to act on them.

MSFT RSI of 58.9 signals bullish momentum — AMZN RSI of 38.7 signals oversold potential

The 14-period Relative Strength Index (RSI) measures the speed and magnitude of recent price movements. Readings above 70 suggest overbought conditions (potential reversal); readings below 30 suggest oversold conditions (potential recovery).

MSFT sits at 58.9 — bullish momentum territory, indicating buyers are still in control. AMZN at 38.7 suggests oversold conditions — a potential entry point for investors who use technical analysis as a timing tool. Both are in the same sector but moving in opposite directions.

This divergence is actionable. A tactical allocation strategy could reduce MSFT exposure if it crosses into overbought territory (above 70) while adding to AMZN positions when RSI remains below 40. The out-of-sample validation (2023–2024) confirmed that this approach generated meaningful alpha over a simple buy-and-hold strategy.

So what?Divergent momentum signals create tactical opportunities even within a single sector. This analysis provides the quantitative foundation for systematic rebalancing — not discretionary timing. RSI is a timing signal, not a prediction, and should be used as an input to a broader allocation framework.

Recommendations

What should actually happen next — and for whom?

Portfolio Managers

Use MSFT as core holding, TSLA as satellite

MSFT offers the best risk-adjusted return in the group — 158% returns with only 24.5% volatility. TSLA's 343.9% return is compelling but comes with 52.3% volatility. Use MSFT as a core holding (10–15% allocation) and TSLA as a tactical position limited to 5–10% of the portfolio. Never size TSLA the same as MSFT — the risk profiles are fundamentally different.

Risk Management

Implement dynamic position sizing based on volatility

Position sizes should be inversely proportional to volatility. Larger positions in MSFT and AAPL (lower volatility), smaller in TSLA and GOOGL. This approach reduces portfolio drawdowns during market stress while preserving upside. The volatility data provides the empirical foundation for this sizing framework.

Tactical Allocation

Use RSI divergence as a rebalancing signal

Add to AMZN positions when RSI falls below 40 — historically this oversold signal has preceded mean-reversion recoveries. Reduce MSFT exposure if RSI exceeds 70 (overbought territory). The out-of-sample validation confirms this approach generated alpha over a simple buy-and-hold strategy.

Institutional Investors

Tech alpha persistence justifies strategic allocation

The tech sector's persistent alpha generation — 243% average return vs 100% benchmark — makes a compelling strategic allocation thesis. This data provides the quantitative foundation for that argument in investment committee presentations. The moderate correlations (0.22 avg) confirm that tech allocation should be complemented with non-tech assets for true diversification.

Limitations & what would improve this analysis

Every honest analysis documents what it cannot do. These are the most important limitations of this project and how they would be addressed with more resources.

What this analysis cannot fully answer — and why

  • Backtested performance ≠ future returns. This analysis is a quantitative backtest, not a live trading system. Historical performance does not guarantee future results. The out-of-sample validation on 2023–2024 provides some evidence of robustness — but a longer out-of-sample period would increase confidence.
  • Limited to 5 tech stocks. This analysis focuses on a small subset of large-cap tech stocks (AAPL, AMZN, GOOGL, MSFT, TSLA). It does not cover mid-cap tech, non-tech sectors, or international markets. A broader universe would improve the generalisability of the findings.
  • Single-sector concentration. The moderate correlations (0.22 avg) confirm that tech alone is not a diversified portfolio. Any portfolio built solely on this analysis would be concentrated in a single sector — increasing systemic risk. Broader market exposure is required for true diversification.
  • Technical indicators are timing tools, not predictions. RSI is a momentum indicator that suggests overbought or oversold conditions. It does not predict future prices with certainty. Any trading strategy based on RSI signals should use position sizing and stop-loss discipline — no indicator works 100% of the time.
  • No fundamental analysis included. This analysis focuses on price data and momentum signals. It does not incorporate earnings growth, revenue multiples, or other fundamental factors that professional equity analysts consider. A combined approach — quantitative price signals + fundamental valuation — would be more comprehensive.

Methodology

Four analytical tools were used in sequence — each answering questions the previous tool could not. The full pipeline is documented and reproducible on GitHub.

Python

Pandas for data manipulation, NumPy for calculations, Matplotlib & Seaborn for visualisations. Jupyter notebooks for exploratory analysis with narrative commentary.

Streamlit

Interactive dashboard with tabs for returns, volatility, correlation, and RSI analysis. Allows users to filter by stock and view metrics on demand.

PostgreSQL

All financial data stored in a structured database with window functions for rolling calculations and data quality validation. Exported as CSV for Tableau and Streamlit.

Tableau

Interactive dashboard with 5 sheets: returns, volatility, correlation, RSI, and risk-return scatter. Used for presentation-ready visualisations.
